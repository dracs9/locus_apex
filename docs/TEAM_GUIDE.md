# Applyra: работа команды в dev

Разрабатываем React + FastAPI версию в `dev`. Старый статический прототип и его опубликованный адрес — отдельный проект: push в этот репозиторий сам по себе его не обновляет.

## Что изменилось

- Ученики 9–12 классов; год поступления по-прежнему предполагает выпуск после 12 класса. Его можно изменить в профиле.
- Manrope, синий акцент, светлый фон и тёмная тема. Векторный знак: `frontend/public/applyra-mark.svg`; React-компонент: `frontend/src/components/brand/Logo.tsx`.
- Самостоятельный ввод собственного годового вклада в USD, включая обучение и проживание. Ноль означает необходимость полного покрытия. UI принимает целые суммы 0–500 000. Финпомощь рассматривается, когда стоимость выше вклада; это не гарантия гранта. Поле API `needs_aid` сохранено для старых клиентов, новая анкета отправляет `true`.
- Академическая шкала 4, 5, 100 или IB MYP / 8. Ползунки оценок и экзаменов; экзамен можно оставить пустым. Исходные оценки хранятся в `academic_record`.
- RIASEC: 30 авторских вопросов, шесть направлений интересов, пять блоков. Результат предлагает специальности, которые ученик подтверждает или меняет. Повторное прохождение доступно через «Мои интересы».
- Основное меню содержит страны. Подборка сгруппирована по стране, есть фильтры страны и сложности; на каждой карточке указана страна. Ссылка вида `/recommendations?country=US` открывает фильтр. Фильтр не меняет анкету.

## Важные ограничения данных

В текущем seed США представлены 19 вузами. Гонконг, Китай и Италия доступны как предпочтения, но пока не имеют записей в каталоге этой ветки; анкета помечает их «скоро». Добавляйте проверенные записи в `supabase/seed`, затем обновляйте БД штатным seed-процессом. Не заполняйте пробелы выдуманными требованиями.

IB / 8 — критерий MYP, а не итоговая предметная оценка 1–7 и не сумма Diploma. Значения IB и процентной шкалы не переводятся автоматически в GPA: движок показывает недостающие сопоставимые данные. Старое `gpa5` читается для совместимости; его перевод остаётся приблизительным.

Тест основан на модели Холланда, но **не копирует и не является официальным тестом Truity**. Он не прошёл психометрическую валидацию. Результаты описывают интересы, а не способности или вероятность поступления. При равных баллах порядок букв условный; при полностью ровном профиле направления автоматически не выбираются.

Канонические вопросы: `backend/app/data/holland.json`; копия для интерфейса: `frontend/src/data/holland.json`. Тест проверяет равенство файлов. Сумма каждой шкалы 0–20. Движок использует интересы в существующем факторе соответствия направлению (вес 0.10), только среди выбранных учеником специальностей. Шансы рассчитывает прежний детерминированный движок.

Источники модели и шкал:
- [Holland Code Career Test, Truity](https://www.truity.com/test/holland-code-career-test)
- [O*NET Interest Profiler](https://www.onetcenter.org/IP.html)
- [IB MYP mathematics: критерии](https://www.ibo.org/globalassets/new-structure/brochures-and-infographics/pdfs/myp-brief-mathematics-en.pdf)
- [IB MYP: итоговые оценки](https://ibo.org/programmes/middle-years-programme/assessment-and-exams/grading-and-awards/)

## Запуск и публикация

Полная инструкция и переменные окружения — в корневом README. Нужны настроенные Supabase Auth/Postgres, API и frontend. Текущая авторизация унаследована из dev: анонимная сессия Supabase в браузере; email-регистрация пока не реализована. Секреты хранятся только в окружении, `.env` не коммитить.

Новые поля профиля находятся в JSON payload, SQL-миграция не нужна. Backend и frontend обновлять вместе. После изменения схемы:

```sh
cd backend
python scripts/dump_openapi.py
cd ../frontend
npm run gen:api
```

Проверки:

```sh
cd backend
pytest -q
cd ../frontend
npm ci
npm test
npm run build
```

Для проверки интерфейса использовался отдельный локальный API с вымышленным пользователем. Этот тестовый запуск не входит в репозиторий и не должен публиковаться. Production требует настоящий Supabase JWT.

Проверены: 49 backend-тестов, 14 frontend-тестов, TypeScript и production-сборка; полный onboarding в браузере, сохранение IB/RIASEC, страны и мобильная ширина 390 px.

## Ветки

Рабочая ветка — `dev`. При проверке прав GitHub текущий аккаунт имеет `push`, но не `admin`: default branch всё ещё `main`. Владельцу dracs9 нужно установить `dev` в Settings → General → Default branch; после этого удалить `main`. Не заменяйте это удалением файлов или force push. Локальная резервная копия старой ветки сохранена отдельно.
